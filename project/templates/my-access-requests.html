Access Request Lifecycle

1. Request Submitted

The user submits an access request from the item details page.

Request date, user account and item record are recorded.

2. Staff Review

Library staff review the request reason, item metadata and current access status.

Metadata and access conditions are checked.

3. Community / Elder Review

Community reviewers or cultural advisors may provide comments for culturally sensitive items.

Consultation comments are recorded.

4. Decision Recorded

The final access decision is recorded and the user can view the outcome.

Status may be approved, rejected or require further review.

5. Library Viewing Arranged

Approved users receive access conditions and instructions for viewing materials at the physical library.

Some materials may require supervised viewing in a designated library space.

CARE Principles

Indigenous Data Governance

Indigenous collection data is handled with attention to collective benefit, community authority, responsibility, ethics and respectful access conditions.

Collective Benefit

Collection data should support Indigenous communities, cultural knowledge protection, equitable outcomes and respectful access to information.

Authority to Control

Indigenous rights and interests in Indigenous data should be recognised, including appropriate authority over culturally sensitive knowledge.

Responsibility

Users, staff and reviewers share responsibility for respectful relationships, careful handling of records and appropriate use of item metadata.

Ethics

Access decisions should minimise harm, maximise benefit, support justice and consider future use of collection information.

Privacy Notice

How User Information Is Used

When a user submits an access request, the library may collect information such as name, email address, account role, request reason, preferred viewing date and request history.

This information is used to assess access requests, communicate outcomes, maintain accountable access records and support appropriate collection management.

  • Personal information is only used for library access and review purposes.
  • Request records are available only to the requester and authorised staff.
  • Reviewer comments and decision notes are restricted to authorised roles.
  • Sensitive item metadata is managed according to access status and review requirements.
  • Users may contact library staff about access to, or correction of, their account information.

Responsible Data Use

User Responsibilities

Users who request access to restricted or culturally sensitive materials must use approved materials only for the stated purpose of their request.

Access approval does not automatically permit copying, publication, redistribution, commercial use, public display or sharing with other people.

  • Follow all access conditions recorded in the review decision.
  • Do not reproduce restricted material without further permission.
  • Acknowledge relevant communities, families or speakers where required.
  • Contact library staff if the intended use changes after approval.
  • Report any accidental disclosure or misuse of restricted material.

Access Protocols

Collection Access Levels

Access statuses explain whether an item can be viewed immediately, requires review, or is awaiting cultural assessment.

Access Status Meaning User Action Review Requirement
Open Item can be viewed through standard catalogue access. View item details. No special review required.
Restricted Item requires an access request before viewing. Login and submit an access request. Staff and/or community review required.
Culturally Sensitive Item may include sensitive cultural knowledge, language, ceremony, family or site information. Submit a detailed request reason. Community reviewer, Elder or administrator decision required.
Pending Item has been added but has not yet completed review. No access request available yet. Metadata and cultural review required before access status is set.

Privacy Practice

Personal Information Handling

The library applies privacy-aware practices when handling personal information connected to user accounts, access requests, reviewer actions and decision records.

Collection limitation: Only information needed to manage access requests and library services should be collected.
Access control: Personal information, request reasons and reviewer notes are limited to authorised users.
Security and accountability: Access decisions, comments and request changes should be recorded and protected.

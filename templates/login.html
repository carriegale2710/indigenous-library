Account Roles

Who can sign in?

The Collections Access Service supports different user roles so that collection access, cultural review and administrative actions can be managed safely.

Public User

Can browse catalogue records, view open items, submit access requests and track request outcomes.

Library Staff

Can support catalogue management, access request administration and supervised viewing arrangements at the library.

Community Reviewer / Elder

Can review culturally sensitive items, add consultation comments and support access decisions.

Admin

Can manage users, item records, metadata, access decisions and protected review areas.
